INTEL BRIEFING

MISSION

Mr. Ghost's Digital Frontier (MGDF) consolidates the community's browser-ported and recompiled AAA titles into a single holographic interface. Every link routes to the original host maintained by its creator.

ORIGIN

Source directory: Browser Games Hub (browser.wix3.com), refreshed from the community-maintained awesome-decomp-games list. Credits to all reverse-engineers and port authors.

LAUNCH PROTOCOLS

  • INSTANT starts directly in your browser.
  • FILES requires game assets from a copy you own.
  • MULTI supports multiplayer sessions.

SAFETY & RIGHTS

Third-party destinations; rights and safety are not verified. Never install a launcher or extension a game site pushes. MGDF merely indexes public links.

CONTROLLER LAB

MGDF uses the browser Gamepad API. Pair a Bluetooth or USB controller in your OS, then open this site; supported games can read inputs directly in their own tab.

  1. Put controller in pairing mode (hold PS/Xbox/menu button).
  2. Pair in OS Bluetooth settings.
  3. Press any button on the controller to wake the browser input.
  4. Launch a game; many community ports read gamepads natively.
